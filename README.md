# 🛡️ ML-Based Women's Safety System with Real-Time Alerts and Geo-Tracking

A machine learning-based safety system that detects emergency situations using sensor data and triggers real-time GPS tracking and SMS alerts.

---

## 📌 Overview

This project addresses women's safety by using accelerometer and gyroscope sensor data to recognize suspicious or distress activity patterns. The system automatically detects emergencies and sends real-time location alerts to trusted contacts.

---

## 🚀 Features

- 📊 **Activity Recognition** using sensor data (accelerometer + gyroscope)
- 🤖 **Multiple ML Models** — Random Forest, SVM, KNN, and Voting Ensemble
- 📍 **Real-Time GPS Tracking** for location sharing
- 📲 **Automated SMS Alerts** triggered on emergency detection
- ✅ **95% Accuracy** achieved with Voting Ensemble model

## 🔄 How It Works

1. **Sensor Data Collection** — Accelerometer and gyroscope data is collected
2. **Preprocessing** — Data is cleaned and features are extracted
3. **Model Training** — Multiple ML models are trained and evaluated
4. **Emergency Detection** — The best model detects distress activity in real time
5. **Alert Trigger** — GPS location is captured and SMS alert is sent to contacts
